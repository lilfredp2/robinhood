How it works

One data file

The whole page reads data/portfolio.json. Swap that file — by hand or from a script — and every number, chart and row updates. Nothing else to change.

No build, no dependencies

Plain HTML, CSS and one ES module. Open index.html over any static server and it runs. Deploys to GitHub Pages as-is.

Readable by design

Charts ship with a legend, direct labels, keyboard-reachable tooltips and a table view. The palette is validated for color-vision deficiency in both light and dark themes.
